🗂 Control Classifier

Sort security controls by category and type (SY0-701 1.1).

What is it?

Every security control has a category — who/what implements it (Technical, Managerial, Operational, Physical) — and a type — what it does to a threat (Preventive, Deterrent, Detective, Corrective, Compensating, Directive). Exam questions often hinge on telling these apart.

⚠️ Common Mix-ups

  • Signs and lighting deter; locks and mantraps prevent
  • CCTV records (detective) but also deters
  • Policies are managerial & directive — they tell people what to do
  • A compensating control substitutes when the primary control is not feasible

🛡 Defence in Depth

  • Layer controls of different types around each asset
  • Pair every preventive control with a detective one
  • Document compensating controls with an exception and review date
  • Map controls to a framework (e.g. NIST CSF, ISO 27001)

🧭 Zero Trust & Deception

Policy decisions, AAA and deception technology (SY0-701 1.2).

What is it?

Zero Trust means "never trust, always verify": every request is evaluated on identity, device and context. In the control plane, the Policy Engine decides and the Policy Administrator issues the instruction; together they form the Policy Decision Point (PDP). In the data plane, the Policy Enforcement Point (PEP) allows or blocks the session. Deception technology (honeypots, honeyfiles, honeytokens) plants decoys that no legitimate user should touch — any access is a high-fidelity alert.

⚠️ Warning Signs

  • Implicit trust because a request comes from "inside" the network
  • Long-lived sessions never re-evaluated
  • Any touch of a honeyfile, honeytoken or honeypot
  • Impossible travel between two logins

🛡 Defences

  • Adaptive identity: combine identity, device and context signals
  • Least privilege and micro-segmented access
  • Seed decoy credentials and files; alert on any use
  • Log every decision for accounting (the third A in AAA)

🧱 Firewall Rule Builder
Ordered ACLs, first-match logic, implicit deny and segmentation (SY0-701 3.2).

      

      

        
What is it?

        
A firewall evaluates its access-control list top-down and applies the first rule that matches. If nothing matches, the implicit deny drops the packet. Segmentation places systems in zones (DMZ, internal, management) so that a compromise in one zone cannot reach everything else. A WAF adds Layer-7 inspection of HTTP content.

🔍 Data Classification & DLP
Find sensitive data, classify it, then mask or tokenise it (SY0-701 3.3).

      

      

        
What is it?

        
Data classification labels information by sensitivity (e.g. Public, Internal, Confidential, Restricted). Data Loss Prevention (DLP) inspects data in use, in motion and at rest for patterns such as national ID numbers or payment cards, then warns, blocks or encrypts. Masking hides part of a value; tokenisation replaces it with a random token whose real value lives only in a secure vault.

  • Bulk exports sent to personal addresses
  • Pattern matches with no validation (false positives)
  • Unlabelled documents with sensitive content

  • Classify at creation; label and handle by policy
  • Validate matches (checksums, Luhn) to cut noise
  • Tokenise card data to shrink PCI DSS scope
  • Minimise collection — PDPA requires a purpose for NRIC collection

      

    


    
    

      

        
💾 Resilience Planner
RAID, backups, RPO/RTO and the 3-2-1 rule (SY0-701 3.4).

      

      

        
What is it?

        
RAID spreads data across disks for performance and/or fault tolerance — but RAID is not a backup. Backups protect against deletion, corruption and ransomware. The Recovery Point Objective (RPO) is how much data you can afford to lose; the Recovery Time Objective (RTO) is how long you can afford to be down.

⚠️ Warning Signs
  • Treating RAID or replication as a backup
  • Backups never restored in a test
  • All copies reachable with the same admin credentials
  • Backup interval longer than the RPO

  • 3-2-1 (or 3-2-1-1-0) backup rule

  • RAID 6 or 10 for large disks with long rebuilds

📱 MFA & TOTP
Generate real RFC 6238 time-based one-time passwords (SY0-701 4.6).

      

      

        
What is it?

        
Multifactor authentication combines different factor types: something you know, have, are, or somewhere you are. A TOTP authenticator app shares a secret with the server; both compute HMAC-SHA1(secret, floor(time / 30)), truncate it to 6 digits, and compare. No network connection is needed — just synchronised clocks.

🚨 Incident Response
IR lifecycle and order of volatility (SY0-701 4.8).

      

      

        
What is it?

        
The SY0-701 incident response process runs Preparation → Detection → Analysis → Containment → Eradication → Recovery → Lessons learned. During forensic acquisition, collect the most volatile evidence first (it disappears on power-off), hash every image, and keep a chain of custody.
